# Portfolio

> A cinematic developer portfolio built with React, TypeScript, Framer Motion, and GSAP.

A personal portfolio designed as an experience rather than a static webpage.

The site blends storytelling, motion design, ambient audio, interactive cursor effects, and project showcases to create an immersive representation of my work, interests, and approach to building software.

## Running Locally

### Clone the repository

```bash
git clone <your-repository-url>
cd portfolio
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Design Philosophy

This portfolio was built around three ideas:

### Story Over Resume

Instead of presenting information as a list of achievements, the site focuses on narrative, personality, and intent.

### Motion With Purpose

Animations are used to guide attention, reinforce hierarchy, and create atmosphere rather than serve as decoration.

### Engineering Meets Design

The project combines frontend engineering practices with interactive design principles to create an experience that feels memorable while remaining performant and maintainable.
